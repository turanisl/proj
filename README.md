# proj

A simple command line calculator written in Python. A basic Tkinter GUI is also available.

## Usage

```
python calculator.py add 1 2
python calculator.py sub 5 3
python calculator.py mul 4 3
python calculator.py div 10 2
```

Run the GUI version:

```
python gui_calculator.py
```

## Running tests

```
python -m unittest
```
