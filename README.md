# proj

A simple command line calculator written in Python. A basic Tkinter GUI is also available.

## Usage

```
python3 calculator.py add 1 2
python3 calculator.py sub 5 3
python3 calculator.py mul 4 3
python3 calculator.py div 10 2
```

Run the GUI version:

```
python gui_calculator.py
```

## Running tests

```
python3 -m unittest
```
